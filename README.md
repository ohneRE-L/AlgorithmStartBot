# Telegram бот для анализа аэрофотоснимков

Прототип Telegram-бота для автоматизации процесса анализа данных с БПЛА (ортофотопланов) компании "ГеосАэро".

## Описание

Бот позволяет сотрудникам компании:
1. Выбирать алгоритм анализа из предложенного списка
2. Загружать файлы с данными аэрофотосъемки
3. Автоматически проверять корректность загруженных файлов
4. Запускать анализ на сервере алгоритмов
5. Получать результаты анализа в чате

## Установка

1. Клонируйте репозиторий или скачайте файлы проекта

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

4. Получите токен бота у [@BotFather](https://t.me/BotFather) в Telegram и добавьте его в `token.env` или `.env`:
```
BOT_TOKEN=ваш_токен_бота
```

5. **Настройте базу данных:**
   - Установите PostgreSQL 15+ локально
   - Создайте базу данных и выполните SQL скрипт `database/init.sql`
   - Добавьте параметры БД в `token.env`:
   ```
   DB_USER=postgres
   DB_PASS=ваш_пароль_postgres
   DB_NAME=agro_bot_db
   DB_HOST=localhost
   DB_PORT=5432
   ```

6. (Опционально) Для загрузки файлов до 2000 МБ настройте локальный сервер Bot API:
   - **Для Windows:** См. [документацию Telegram](https://core.telegram.org/bots/api#using-a-local-bot-api-server)
   - После установки добавьте в `token.env` или `.env`:
   ```
   LOCAL_BOT_API_URL=http://localhost:8081
   ```
   - Без локального сервера максимальный размер файла - 20 МБ

## Запуск

## Использование

1. Запустите бота командой `/start`
2. Нажмите кнопку "📋 Выбрать алгоритм"
3. Выберите нужный алгоритм из списка
4. Загрузите файл с данными (поддерживаются: .tif, .tiff, .geotiff, .jpg, .jpeg, .png)
5. Дождитесь завершения анализа
6. Получите результат в чате

## Доступные алгоритмы

1. **Классификация сельскохозяйственных земель** - автоматическая классификация типов сельскохозяйственных угодий
2. **Расчет вегетационных индексов** - NDVI, EVI и другие индексы растительности
3. **Детекция объектов** - обнаружение и классификация объектов на снимках
4. **Детекция изменений** - выявление изменений между снимками разных периодов

## Интеграция с сервером алгоритмов

Для интеграции с реальным сервером алгоритмов необходимо:

1. Обновить `ALGORITHM_SERVER_URL` в `.env`
2. Реализовать реальные методы в `server_client.py`:
   - `start_analysis()` - отправка файла и запуск анализа
   - `check_status()` - проверка статуса задачи
   - `get_result()` - получение результата

Сервер должен предоставлять API эндпоинты:
- `POST /api/start_analysis` - запуск анализа
- `GET /api/task/{task_id}/status` - статус задачи
- `GET /api/task/{task_id}/result` - получение результата
